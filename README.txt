ACME SWITCHGEARS - CRM & ERP (standalone web app)

HOW TO USE
1. Unzip this folder.
2. Double-click index.html (opens in Chrome / Edge / Firefox).
   Internet is needed once per session for the PDF and Excel libraries (cdnjs.cloudflare.com).

DATA
- All records are saved in this browser (localStorage), not on a server.
- Use Settings > "Download backup (JSON)" regularly. Clearing browser data erases records.
- Different browser or computer = separate data.

INCLUDED
Dashboard, Leads, Customers, Products, Inventory, Quotations (PDF in ACME format), Invoices,
Purchases, Suppliers, Accounts (expenses), HR, Reports (CSV / Excel / PDF), Settings.

NOT INCLUDED (needs a real server + database)
Login & roles, PostgreSQL storage, website enquiry API, WhatsApp/email sharing.
